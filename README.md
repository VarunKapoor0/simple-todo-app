# Simple Todo App

A clean, keyboard-driven todo app with categories and priority levels that stores data locally without requiring accounts or installation.

## Planned Features

- **todo_management**: Add, complete, and delete todo items with text descriptions
- **categories**: Group todos into predefined categories with the ability to add custom categories, and filter by category
- **priority_levels**: Assign high, medium, or low priority to todos with visual differentiation
- **keyboard_shortcuts**: Provide keyboard commands for all primary actions (add, complete with spacebar, delete, save)
- **local_persistence**: Store all data locally in the browser without requiring accounts or logins
- **data_export**: Export todos to a portable format
- **dark_mode**: Provide a dark color theme option
- **modern_ui**: Clean, contemporary interface design

## Non-Functional Requirements

- browser-based, no installation required
- works on both macOS and Windows
- data stored locally (no cloud sync)
- no authentication or user accounts
- self-hostable

## Tech Stack

- **Language:** Python
- **Backend:** Flask
- **Frontend:** HTML + Tailwind CDN + vanilla JS
- **Storage:** JSON file (server-side)
